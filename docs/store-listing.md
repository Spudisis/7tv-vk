# Карточка Chrome Web Store

Тексты и параметры для публикации расширения в Chrome Web Store
(он же покрывает Яндекс Браузер). Обновлять перед каждой публикацией.

Пакет для загрузки собирается командой `./build.sh --store` →
`dist/vk7tv-<версия>-store.zip` (плоский zip, `manifest.json` в корне).

## Короткое описание (summary, до 132 символов)

```
Анимированные эмоуты 7TV в сообщениях и ленте ВКонтакте. Пишешь код-слово — виден эмоут. Неофициальное расширение.
```

## Description (подробное)

```
VK7TV показывает анимированные эмоуты 7TV прямо во ВКонтакте.

Пишешь в сообщении или комментарии код-слово (например, peepoHappy) — и вместо текста появляется анимированный эмоут. На сервере ВКонтакте при этом остаётся обычный текст: у кого расширения нет, тот просто видит слово. Ничего особенного при отправке делать не нужно.

Возможности:
• Глобальный набор 7TV из коробки — популярные эмоуты доступны сразу.
• Наборы стримеров — добавь по ссылке с 7tv.app или по нику с Twitch, и весь набор подключится целиком.
• Общий набор с друзьями — все, кто добавил один и тот же набор, видят одинаковые картинки под одним словом.
• Свои эмоуты — добавленный ссылкой с 7tv.app виден и собеседнику, даже если этого набора у него нет; ему остаётся нажать «+ себе». Можно и прямой ссылкой на гифку, если чего-то нет на 7TV.
• Автозаполнение при наборе, как на Twitch.
• Виджет-пикер на странице — поиск, недавние, избранное и все эмоуты по наборам в один клик. Открывается и по Ctrl+Shift+E, эмоут вставляется с клавиатуры. Внутри набора эмоуты стоят по размеру: сперва квадратные, потом широкие, и сетка не дёргается, пока картинки грузятся.
• Пока картинка эмоута загружается, в сообщении видно его имя — сообщение читается сразу, а не выглядит пустым.
• Клик по незнакомому эмоуту в сообщении открывает набор, из которого он.
• Наборы сворачиваются и переставляются перетаскиванием; порядок решает, чья картинка встанет под общим кодом.
• Zero-width эмоуты накладываются поверх предыдущего, как на 7TV.
• Спойлеры: [spoiler]текст[/spoiler] прячет под блюром текст, [spoiler/] — всё содержимое сообщения вместе с фотографиями. Одно слово spoiler или спойлер, если в сообщении больше ничего нет, делает то же самое. Клик открывает. Тег ставится и кнопкой в панели форматирования ВКонтакте, если выделить текст в поле ввода.
• По умолчанию эмоуты только в переписке; галка «Показывать эмоуты везде» включает их по всему ВК — в ленте, на стене, в комментариях.

Как это работает и приватность:
Замена кодов на картинки происходит только в вашем браузере. Расширение не отправляет ваши данные ни на какой сервер. Наборы и картинки эмоутов загружаются напрямую с 7TV (7tv.io, cdn.7tv.app) — если эти адреса у вас не открываются, наборы не скачаются, и расширение прямо скажет, какие именно. Политика конфиденциальности: https://github.com/Spudisis/7tv-vk/blob/main/PRIVACY.md

Неофициальное расширение. Не связано с ВКонтакте (VK) и с 7TV и не одобрено ими; все названия и товарные знаки принадлежат их владельцам.
```

## Вкладка Privacy practices

- **Single purpose:** «Оформляет сообщения на страницах ВКонтакте: заменяет
  коды-слова 7TV на анимированные эмоуты и прячет отмеченное тегом спойлера».
  Формулировку расширили в 0.20.0: одной заменой кодов спойлеры не
  покрываются, а несоответствие заявленной цели — повод для отказа.
- **Обоснование прав:**
  - домены VK (`vk.com`, `vk.ru`, `vk.me`) — где происходит замена кодов;
  - `7tv.io`, `cdn.7tv.app`, `api.ivr.fi` — откуда качаются наборы и картинки эмоутов;
  - `storage` / `unlimitedStorage` — хранить настройки и кэш картинок локально.
- **Data usage:** данные не собираются и не продаются.
