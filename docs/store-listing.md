# Карточка Chrome Web Store

Тексты и параметры для публикации расширения в Chrome Web Store
(он же покрывает Яндекс Браузер). Обновлять перед каждой публикацией.

Пакет для загрузки собирается командой `./build.sh --store` →
`dist/vk7tv-<версия>-store.zip` (плоский zip, `manifest.json` в корне).

- **Category:** Social & Networking (альтернатива — Just for Fun).

## Короткое описание (summary, до 132 символов)

```
Анимированные эмоуты 7TV в сообщениях и ленте ВКонтакте. Пишешь код-слово — виден эмоут. Неофициальное расширение.
```

## Description (подробное)

```
VK7TV показывает анимированные эмоуты 7TV прямо во ВКонтакте.

Пишешь в сообщении или комментарии код-слово (например, peepoHappy) — и вместо текста появляется анимированный эмоут. На сервере ВКонтакте при этом остаётся обычный текст: у кого расширения нет, тот просто видит слово. Ничего особенного при отправке делать не нужно.

Возможности:
• Глобальный набор 7TV из коробки — популярные эмоуты доступны сразу.
• Наборы стримеров — добавь по ссылке с 7tv.app или по нику с Twitch, и весь набор подключится целиком.
• Общий набор с друзьями — все, кто добавил один и тот же набор, видят одинаковые картинки под одним словом.
• Свои эмоуты — имя и ссылка на гифку, если чего-то нет на 7TV.
• Автозаполнение при наборе, как на Twitch.
• Виджет-пикер на странице — поиск, избранное и все эмоуты по наборам в один клик.
• Режим «только в мессенджере» — заменять коды лишь в переписке, не трогая ленту, стену и комментарии.

Как это работает и приватность:
Замена кодов на картинки происходит только в вашем браузере. Расширение не отправляет ваши данные ни на какой сервер. Наборы и картинки эмоутов загружаются напрямую с 7TV (7tv.io, cdn.7tv.app). Политика конфиденциальности: https://github.com/Spudisis/7tv-vk/blob/main/PRIVACY.md

Неофициальное расширение. Не связано с ВКонтакте (VK) и с 7TV и не одобрено ими; все названия и товарные знаки принадлежат их владельцам.
```

## Вкладка Privacy practices

- **Single purpose:** «Заменяет коды-слова 7TV на анимированные эмоуты на страницах ВКонтакте».
- **Обоснование прав:**
  - домены VK (`vk.com`, `vk.ru`, `vk.me`) — где происходит замена кодов;
  - `7tv.io`, `cdn.7tv.app`, `api.ivr.fi` — откуда качаются наборы и картинки эмоутов;
  - `storage` / `unlimitedStorage` — хранить настройки и кэш картинок локально.
- **Data usage:** данные не собираются и не продаются.

## Риск с товарными знаками

Названия «ВКонтакте» и «7TV» — чужие марки, Google может придраться.
Дисклеймер про «неофициальное расширение» уже вставлен в оба текста — этого
обычно достаточно.
