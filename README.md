# VK7TV — эмоуты 7TV во ВКонтакте

Расширение для Chrome, которое работает как прослойка над [7TV](https://7tv.app):
слова-коды в сообщениях и ленте ВК заменяются на анимированные эмоуты из наборов 7TV.

Пишешь другу `peepoHappy` — у всех, у кого стоит расширение, вместо слова
рендерится гифка. На сервере ВК при этом остаётся обычный текст, поэтому никакой
магии с отправкой не нужно: у кого расширения нет, тот просто видит слово.

## Как это работает

- Наборы эмоутов живут на 7tv.app — там их создаёшь и редактируешь.
- Расширение тянет наборы через открытый API `7tv.io/v3/emote-sets/{id}`
  и кэширует локально (обновление каждые 30 минут).
- Контент-скрипт на vk.com / web.vk.me находит слова-коды в тексте
  и подменяет их на `<img>` с CDN 7TV.
- Из коробки включены глобальный набор 7TV (~45 эмоутов: peepoHappy, EZ, Clap,
  gachiBASS…) и набор bratishkinoff (~1000 эмоутов). Набор стримера подключается
  один раз при установке — если удалить его из списка, сам не вернётся.

## Установка

1. Скачай архив со [страницы релизов](https://github.com/Spudisis/7tv-vk/releases)
   (или «Code → Download ZIP» — но тогда качай **весь** архив целиком)
2. Распакуй в постоянную папку — если папку удалить или переименовать,
   расширение отвалится
3. Открой `chrome://extensions` (в Яндекс Браузере — `browser://extensions`)
4. Включи «Режим разработчика» (справа сверху)
5. «Загрузить распакованное расширение» → выбери папку, в которой лежит `manifest.json`

## Обновление

Заменяй **всю папку целиком**, а не отдельные файлы: в новых версиях
появляются новые файлы, и манифест на них ссылается. После замены зайди
в `chrome://extensions` и нажми «Обновить» на карточке расширения.

### Ошибка «Не удалось загрузить JavaScript … для скрипта содержимого»

Значит в папке не хватает файла, указанного в `manifest.json` — браузер
в таком случае отказывается ставить расширение целиком. Почти всегда это
результат обновления по частям: например, `picker.js` появился только
в версии 0.5.0, и если заменить один `manifest.json`, загрузка упадёт.

Собрать архив самому: `./build.sh` — он проверяет, что все файлы из
манифеста на месте, и кладёт `dist/vk7tv-<версия>.zip`.

## Наборы стримеров

В попапе можно вписать просто ник стримера на Twitch — например
`bratishkinoff` или `5opka` — и его активный набор 7TV подключится целиком
(у обоих это ~1000 эмоутов). Ник резолвится в Twitch ID через открытый
api.ivr.fi, запасной путь — поиск в GQL самого 7TV.

## Общий набор с друзьями

1. Зарегистрируйся на [7tv.app](https://7tv.app) (вход через Twitch или Discord)
2. Создай свой emote set и накидай туда эмоутов (можно любые с сайта)
3. Скопируй ссылку на набор (вида `https://7tv.app/emote-sets/01ABC…`)
4. Каждый друг вставляет эту ссылку в попап расширения → «Добавить»

Все, кто добавил один и тот же набор, видят одинаковые эмоуты.
Когда владелец набора добавляет новый эмоут на 7tv.app, он подъезжает
ко всем автоматически при очередном обновлении.

## Zero-width эмоуты

Эмоуты с флагом zero-width в 7TV (RainTime, PETPET, SteerR и другие)
не занимают своё место, а накладываются поверх предыдущего эмоута:
`peepoHappy RainTime` отрисуется как peepoHappy под дождём. Можно
стакать несколько поверх одного. Zero-width без эмоута перед ним
рендерится как обычный.

## Автозаполнение

Работает как на Twitch: набери в поле ввода 3+ символа имени эмоута
(регистр не важен) — всплывёт панель с подходящими вариантами.
Стрелки — выбор, Tab/Enter/клик — вставить, Esc — закрыть.

## Виджет-пикер на странице

В углу страницы ВК висит круглая кнопка «7TV». Клик раскрывает поповер:
поиск и все подключённые эмоуты, сгруппированные по наборам. Клик по
эмоуту вставляет его имя в последнее активное поле ввода (курсор
запоминается); если поле не открыто — имя копируется в буфер.

Кнопку можно перетаскивать (за неё саму или за шапку поповера) —
поповер ездит вместе с ней, позиция запоминается. Поповер можно
ресайзить за правый нижний угол (в разумных пределах, не на весь
экран) — размер тоже запоминается. Отключается галочкой
«Виджет-пикер на странице» в попапе.

## Попап

- Вкл/выкл расширения
- Подключение/отключение наборов 7TV по ссылке
- Свои эмоуты вручную (имя + прямая ссылка на гифку) — на случай,
  если чего-то нет на 7TV
- Сетка всех активных эмоутов с поиском; клик по эмоуту копирует его имя

## Ограничения

- Эмоут — отдельное слово, отделённое пробелами, с учётом регистра
  (`peepoHappy` сработает, `peepohappy` и `peepoHappy,` — нет). Так же работает сам 7TV.
- Гифки видят только те, у кого установлено расширение — остальные видят текст.
- Меняется только текст сообщений и постов. Служебные подписи ВК — время
  сообщения, дата поста, «был в сети…» — не трогаются: в наборах попадаются
  эмоуты с именами вроде `20:00`, и иначе они подменяли бы время. Цена этого —
  сообщение, состоящее ровно из `20:00` и ничего больше, останется текстом;
  внутри фразы (`созвон 20:00`) эмоут рисуется как обычно.
- Работает только в браузере (vk.com, web.vk.me); приложения VK Messenger
  и мобильный клиент не поддерживаются.
- CSP ВКонтакте блокирует прямую загрузку картинок с cdn.7tv.app,
  поэтому все эмоуты качает фоновый скрипт и отдаёт странице как
  blob:-URL (blob: и data: у ВК разрешены). Отсюда и
  `host_permissions: <all_urls>` — чтобы качать и «свои» эмоуты
  с произвольных CDN.

## Файлы

- `manifest.json` — MV3-манифест
- `content.js` / `content.css` — замена слов на эмоуты (MutationObserver, не трогает поле ввода)
- `autocomplete.js` — автозаполнение эмоутов при наборе (Twitch-стиль)
- `picker.js` / `picker.css` — перетаскиваемый виджет-пикер на странице
- `background.js` — загрузка наборов из API 7TV, кэш картинок в data:-URL
- `popup/` — интерфейс управления
- `default-emotes.js` — снапшот глобального набора 7TV (обновляется из API автоматически)
