# VK7TV — эмоуты 7TV во ВКонтакте

Расширение для Chrome, которое заменяет коды эмоутов 7TV на анимированные картинки в сообщениях ВКонтакте. На сервере VK остаётся обычный текст: собеседник без расширения видит код эмоута.

## Возможности

- Глобальный набор 7TV, наборы стримеров по нику Twitch или ссылке на набор.
- Свои эмоуты по ссылке с 7TV или прямой ссылке на картинку.
- Пикер с поиском, избранным и недавними эмоутами; автозаполнение при наборе.
- Перестановка и сворачивание наборов. При совпадении кодов приоритет получает набор выше в списке.
- Наложение zero-width эмоутов поверх предыдущего эмоута.
- Спойлеры для текста и вложений.
- Раздел «Файлы» в пикере: личные документы VK, загрузка и прикрепление к черновику. Анимированный WebP перед загрузкой преобразуется в GIF.
- Резервная копия настроек, наборов и своих эмоутов.

## Установка и обновление

1. Скачайте `vk7tv-<версия>.zip` со [страницы релизов](https://github.com/Spudisis/7tv-vk/releases) и распакуйте его.
2. Откройте `chrome://extensions` и включите «Режим разработчика».
3. Нажмите «Загрузить распакованное расширение» и выберите папку `vk7tv` с файлом `manifest.json`.

Для обновления распакуйте новый архив поверх прежней папки и нажмите кнопку перезагрузки на карточке расширения. Сохраняйте путь к папке и не удаляйте расширение, чтобы не потерять настройки. Перед переустановкой или переносом на другой компьютер сохраните резервную копию через попап расширения.

## Использование

Откройте попап расширения и добавьте набор по ссылке с [7tv.app](https://7tv.app) или нику стримера с Twitch. Чтобы видеть одинаковые эмоуты с друзьями, подключите один и тот же набор. После изменения набора нажмите «Обновить наборы» — автоматически его содержимое не обновляется.

Кнопка «7VK» на странице открывает пикер. Выберите эмоут для вставки в сообщение или начните вводить его имя: автозаполнение появляется от трёх символов. Стрелки выбирают вариант, Tab/Enter вставляет, Esc закрывает панель.

Коды чувствительны к регистру и должны быть отделены пробелами. Имя с постфиксом набора помогает выбрать нужный вариант при совпадении кодов. Эмоуты по умолчанию заменяются в переписке; для ленты и комментариев включите «Показывать эмоуты везде».

### Спойлеры

- `[spoiler]текст[/spoiler]` скрывает фрагмент текста.
- `[spoiler/]` скрывает содержимое сообщения вместе с вложениями.
- Единственное слово `spoiler` или `спойлер` в сообщении также скрывает всё его содержимое.

Нажмите на спойлер, чтобы раскрыть его. Собеседники без расширения видят исходный текст и теги: спойлер не защищает данные от просмотра.

## Ограничения и приватность

- Для загрузки наборов и картинок нужен доступ к сервисам 7TV.
- Раздел «Файлы» поддерживает обычные диалоги нового мессенджера VK; комментарии, каналы и редактирование сообщений не поддерживаются. MP4 можно загрузить и прикрепить, но предпросмотр видео в пикере недоступен.
- Изменения интерфейса VK могут повлиять на работу расширения.
- Для приложения VK на Android есть [отдельный модуль и инструкция](android/README.md).

Обработка данных и используемые разрешения описаны в [политике конфиденциальности](PRIVACY.md).

Проект не связан с VK и 7TV и не одобрен ими.

## Сборка

Нужны Git, Bash и Python 3. Запускайте из корня репозитория:

```bash
./build.sh          # dist/vk7tv-<версия>.zip для ручной установки
./build.sh --store  # дополнительно dist/vk7tv-<версия>-store.zip для Chrome Web Store
```

В архиве для магазина `manifest.json` находится в корне. Скрипт проверяет наличие файлов, указанных в манифесте. Android, тесты и материалы для страницы магазина в сборку не входят.

Браузерные тесты требуют Node.js и Chrome:

```bash
./run-tests.sh
# Если Chrome не найден автоматически:
CHROME='/путь/к/chrome' ./run-tests.sh
```
