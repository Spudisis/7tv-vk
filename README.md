# VK7TV — эмоуты 7TV во ВКонтакте

Расширение для Chrome, которое работает как прослойка над [7TV](https://7tv.app):
слова-коды в сообщениях и ленте ВК заменяются на анимированные эмоуты из наборов 7TV.

Пишешь другу `peepoHappy` — у всех, у кого стоит расширение, вместо слова
рендерится гифка. На сервере ВК при этом остаётся обычный текст, поэтому никакой
магии с отправкой не нужно: у кого расширения нет, тот просто видит слово.

## Как это работает

- Наборы эмоутов живут на 7tv.app — там их создаёшь и редактируешь.
- Расширение тянет наборы через открытый API `7tv.io/v3/emote-sets/{id}`
  и кэширует локально. Кэш живёт до тех пор, пока не нажмёшь
  «↻ Обновить наборы» в попапе: наборы меняются редко, а проверка каждого
  при старте браузера — это лишний запрос к API. Обратная сторона —
  новые эмоуты, добавленные владельцем набора, приедут не сами.
- Контент-скрипт на vk.com / web.vk.me находит слова-коды в тексте
  и подменяет их на `<img>` с CDN 7TV.
- Из коробки включены глобальный набор 7TV (~45 эмоутов: peepoHappy, EZ, Clap,
  gachiBASS…) и набор bratishkinoff (~1000 эмоутов). Набор стримера подключается
  один раз при установке — если удалить его из списка, сам не вернётся.

## Установка

1. Скачай архив со [страницы релизов](https://github.com/Spudisis/7tv-vk/releases)
   (или «Code → Download ZIP» — но тогда качай **весь** архив целиком)
2. Распакуй — внутри лежит папка `vk7tv`. Положи её туда, где она останется
   насовсем: если папку удалить, переименовать или перенести, расширение отвалится
3. Открой `chrome://extensions` (в Яндекс Браузере — `browser://extensions`)
4. Включи «Режим разработчика» (справа сверху)
5. «Загрузить распакованное расширение» → выбери папку `vk7tv`

## Обновление

**Не удаляй расширение** — браузер вместе с ним стирает подключённые наборы,
свои эмоуты и настройки.

1. Скачай новый архив с той же страницы релизов
2. Распакуй его **поверх старой папки** `vk7tv`, заменив файлы
3. В `chrome://extensions` нажми «Обновить» (↻) на карточке расширения

Так наборы остаются на месте. Дело в том, что у распакованного расширения
идентификатор вычисляется из пути к папке: положишь новую версию в папку
`vk7tv-0.8.2` рядом со старой — браузер посчитает её другим расширением
и заведёт ему пустое хранилище, а старое так и останется висеть вторым.
Поэтому в архиве папка всегда называется `vk7tv`, без номера версии.

Если всё-таки надо переустановить с нуля или переехать на другой компьютер,
в попапе есть раздел «Резервная копия настроек»: «Сохранить в файл» перед
удалением и «Загрузить из файла» после установки. Эмоуты наборов в файл
не пишутся — по id набора они докачиваются из API 7TV сами.

### Ошибка «Не удалось загрузить JavaScript … для скрипта содержимого»

Значит в папке не хватает файла, указанного в `manifest.json` — браузер
в таком случае отказывается ставить расширение целиком. Почти всегда это
результат обновления по частям: например, `picker.js` появился только
в версии 0.5.0, и если заменить один `manifest.json`, загрузка упадёт.

Собрать архив самому: `./build.sh` — он проверяет, что все файлы из
манифеста на месте, и кладёт `dist/vk7tv-<версия>.zip`.

## Наборы стримеров

В попапе можно вписать просто ник стримера на Twitch — например
`bratishkinoff` или `5opka` — и его активный набор 7TV подключится целиком
(у обоих это ~1000 эмоутов). Ник резолвится в Twitch ID через открытый
api.ivr.fi, запасной путь — поиск в GQL самого 7TV.

### Постфикс набора

У каждого эмоута из набора есть второе имя — с постфиксом набора:
`ok` работает и как `ok_bratishkinoff`. Постфикс — ник владельца набора
на 7TV, он виден в попапе рядом с названием набора.

Кому достаётся голое имя:

- глобальному набору 7TV и «своим» эмоутам — всегда;
- набору стримера — только если такой код есть ровно в одном подключённом
  наборе;
- если код есть в нескольких наборах, голое имя не работает ни для одного
  из них — пиши с постфиксом. Иначе картинка зависела бы от того, какой
  набор подключён последним, и у вас с другом она могла бы отличаться.

Пикер на странице всегда вставляет имя с постфиксом, но в заголовке
группы постфикс не дублируется — там просто название набора.
Автозаполнение
показывает такие имена, когда в набранном слове есть `_`, — а если голое
имя не работает из-за коллизии, показывает сразу все варианты с постфиксами.

### Предложение подключить набор

Если в чат прилетает слово с постфиксом, а набора у тебя нет — правее слова
появляется чип с превью эмоута и кнопкой «+ ник»: жмёшь, набор подключается,
и слово тут же превращается в картинку во всех сообщениях на странице.

Кандидатом считается слово вида `имя_ник` из латиницы, цифр и подчёркиваний.
Где именно проходит граница, заранее не понять: в `non_nicosl` разделитель
один, а в `SEXALARM_kanba_mx` ник сам с подчёркиванием — стример тут
`kanba_mx`. Поэтому разделители перебираются слева направо (не больше трёх),
и берётся первый вариант, который сходится по API: и стример есть, и эмоут
с таким именем в его наборе лежит. Пока ответ не сошёлся, чипа нет — так
расширение не предлагает наборы на каждое слово с подчёркиванием.

Имя сверяется с учётом регистра: `sexalarm_kanba_mx` чипа не получит,
потому что и после установки набора такое слово не отрендерится.
Ответы (в том числе «не нашлось») кэшируются, так что одно и то же слово
дёргает API один раз. Выключается галкой «Предлагать наборы стримеров
в чате» в попапе.

## Общий набор с друзьями

1. Зарегистрируйся на [7tv.app](https://7tv.app) (вход через Twitch или Discord)
2. Создай свой emote set и накидай туда эмоутов (можно любые с сайта)
3. Скопируй ссылку на набор (вида `https://7tv.app/emote-sets/01ABC…`)
4. Каждый друг вставляет эту ссылку в попап расширения → «Добавить»

Все, кто добавил один и тот же набор, видят одинаковые эмоуты.
Когда владелец добавляет новый эмоут на 7tv.app, он приедет после
«↻ Обновить наборы» в попапе — сам по себе кэш не обновляется.

## Zero-width эмоуты

Эмоуты с флагом zero-width в 7TV (RainTime, PETPET, SteerR и другие)
не занимают своё место, а накладываются поверх предыдущего эмоута:
`peepoHappy RainTime` отрисуется как peepoHappy под дождём. Можно
стакать несколько поверх одного. Zero-width без эмоута перед ним
рендерится как обычный.

## Автозаполнение

Работает как на Twitch: набери в поле ввода 3+ символа имени эмоута
(регистр не важен) — всплывёт панель с подходящими вариантами.
Стрелки — выбор, Tab/Enter/клик — вставить, Esc — закрыть.

## Виджет-пикер на странице

В углу страницы ВК висит круглая кнопка «7TV». Клик раскрывает поповер:
поиск и все подключённые эмоуты, сгруппированные по наборам. Клик по
эмоуту вставляет его имя в последнее активное поле ввода (курсор
запоминается); если поле не открыто — имя копируется в буфер.
Вставляется всегда полное имя с постфиксом набора (`ok_bratishkinoff`),
чтобы эмоут не спутался с одноимённым из другого набора.

### Избранное

Наведи на эмоут — в правом верхнем углу появится звёздочка. Клик по ней
закрепляет эмоут в полосе «Избранное» над списком: она не уезжает
при прокрутке, так что часто используемые всегда под рукой. Клик по
звезде ещё раз — убрать. Полоса занимает максимум две строки, дальше
прокручивается сама, поэтому сколько бы эмоутов ни было в избранном,
поповер не разрастается.

Избранное хранится списком имён и синхронизируется вместе с остальными
настройками, а в резервную копию попадает наравне с наборами. Если
набор отключить, его эмоуты просто перестают показываться в полосе.

Кнопку можно перетаскивать (за неё саму или за шапку поповера) —
поповер ездит вместе с ней, позиция запоминается. Поповер можно
ресайзить за правый нижний угол (в разумных пределах, не на весь
экран) — размер тоже запоминается. Отключается галочкой
«Виджет-пикер на странице» в попапе.

## Попап

- Вкл/выкл расширения
- Подключение/отключение наборов 7TV по ссылке
- Галка «Предлагать наборы стримеров в чате» — чип с кнопкой рядом
  с эмоутом из неподключённого набора
- Свои эмоуты вручную (имя + прямая ссылка на гифку) — на случай,
  если чего-то нет на 7TV
- Сетка всех активных эмоутов с поиском; клик по эмоуту копирует его имя

## Ограничения

- Эмоут — отдельное слово, отделённое пробелами, с учётом регистра
  (`peepoHappy` сработает, `peepohappy` и `peepoHappy,` — нет). Так же работает сам 7TV.
- Гифки видят только те, у кого установлено расширение — остальные видят текст.
- Меняется только текст сообщений и постов. Служебные подписи ВК — время
  сообщения, пометка `(ред.)`, дата поста, «был в сети…» — не трогаются:
  в наборах попадаются эмоуты с именами `20:00`, `(` и `)`, и иначе они
  подменяли бы время и скобки у пометки об изменении. Цена этого —
  сообщение, состоящее ровно из `20:00` и ничего больше, останется текстом;
  внутри фразы (`созвон 20:00`) эмоут рисуется как обычно.
- Само расширение работает только в браузере (vk.com, web.vk.me). Для
  официального приложения ВК на Android есть отдельный модуль — см.
  «Приложение ВК на Android» ниже.
- CSP ВКонтакте блокирует прямую загрузку картинок с cdn.7tv.app,
  поэтому все эмоуты качает фоновый скрипт и отдаёт странице как
  blob:-URL (blob: и data: у ВК разрешены). Отсюда и
  `host_permissions: <all_urls>` — чтобы качать и «свои» эмоуты
  с произвольных CDN.

## Приложение ВК на Android

Расширение — это код в браузере, а в официальном приложении ВК браузера нет.
Поэтому для телефона есть отдельная штука: **модуль**, который цепляется
к процессу ВК и делает там то же самое — подменяет слова-коды на картинки
и добавляет свою кнопку с пикером в панель ввода.

Рут не нужен. Android не даёт одному приложению лезть в процесс другого,
и обходится это через [LSPatch](https://github.com/JingMatrix/LSPatch):
он дописывает в APK ВКонтакте загрузчик модуля. Код самого ВК при этом
не вырезается и не меняется. Плата — обновления приложения придётся
ставить вручную, зато всё обратимо: поставил обычный ВК из Play Store,
и телефон как был.

Настройки не надо заводить заново: в модуле есть импорт того же файла,
который отдаёт «Резервная копия настроек» в попапе расширения. Наборы,
свои эмоуты и избранное приезжают на телефон одним файлом, и вы с другом
видите одинаковые картинки под одним словом — на десктопе и на телефоне.

Подробности, установка и что ломается при обновлении ВК — в
[`android/README.md`](android/README.md).

## Файлы

- `manifest.json` — MV3-манифест
- `content.js` / `content.css` — замена слов на эмоуты (MutationObserver, не трогает поле ввода)
- `autocomplete.js` — автозаполнение эмоутов при наборе (Twitch-стиль)
- `picker.js` / `picker.css` — перетаскиваемый виджет-пикер на странице
- `background.js` — загрузка наборов из API 7TV, кэш картинок в data:-URL
- `popup/` — интерфейс управления, там же резервная копия настроек
- `default-emotes.js` — снапшот глобального набора 7TV (обновляется из API автоматически)
- `android/` — модуль для приложения ВК (в архив расширения не входит)
