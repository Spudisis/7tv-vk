# VK7TV — модуль для приложения ВКонтакте на Android

То же самое, что расширение для браузера, только внутри официального
приложения ВК: слова-коды в сообщениях заменяются на эмоуты 7TV, а в панели
ввода появляется своя кнопка с пикером.

Рут не нужен. Работает не только с официальным приложением, но и
со сторонними клиентами ВК — Sova, Kate и прочими: модуль не проверяет
имя пакета, приложение ты выбираешь сам при патче.

## Как это работает

Android не даёт одному приложению лезть в процесс другого. Обходится это
через [LSPatch](https://github.com/JingMatrix/LSPatch): он дописывает
в APK ВКонтакте загрузчик, который на старте подтягивает модуль. Код
самого ВК при этом не вырезается и не меняется — приложение работает
как обычно, просто рядом с ним теперь живёт наш модуль.

Плата за это одна: у пропатченного APK другая подпись, а Android не
обновляет приложение подписью, отличной от исходной. Значит оригинальный
ВК придётся удалить, а обновления ставить вручную — скачал новую версию,
прогнал через LSPatch, поставил. Минуты две раз в пару недель.

Всё обратимо: удалил пропатченный ВК, поставил обычный из Play Store —
и телефон как был.

Пропатченный APK нельзя раздавать другим. Это чужое приложение под твоей
подписью, по форме неотличимо от подсунутого фейкового клиента. Себе
на телефон — нормально.

## Установка

Нужен Android 9+ (API 28) — ради системного декодера анимированных webp.

1. Поставить [Shizuku](https://shizuku.rikka.app/) и запустить его через
   беспроводную отладку (всё на телефоне, компьютер не нужен). Без него
   LSPatch не сможет сам ставить и удалять APK — придётся руками.
2. Поставить [LSPatch](https://github.com/JingMatrix/LSPatch/releases)
   и APK этого модуля — оба как обычные приложения
3. В LSPatch: **+** → выбрать установленный ВКонтакте → **локальный режим**
4. Пропатчить, удалить оригинальный ВК, поставить полученный APK

Локальный режим важен: он подгружает модули из LSPatch на лету, поэтому
обновление модуля — это просто установка нового APK, **без перепатчивания
ВК**. Во встроенном режиме пришлось бы каждый раз заново.

Перед удалением ВК убедись, что сможешь зайти заново. Переписка на
сервере и никуда не денется, но логиниться придётся с нуля.

После перезагрузки телефона Shizuku выключается — если понадобится
что-то ставить через LSPatch, запусти его снова.

## Настройки

**Долгий тап по круглой кнопке 7TV** внутри ВК. Там наборы, переключатели
и перенос настроек из браузерного расширения.

Отдельного приложения-настройки нет намеренно. Модуль встроен в чужой APK
и до данных своего приложения не дотягивается — `XSharedPreferences` там
не работает. Поэтому конфиг живёт в `SharedPreferences` самого ВК, и раз
он там, то там же и правится. Заодно доступен на запись, так что
избранное меняется прямо из пикера.

Перенести настройки из браузера: в попапе расширения «Резервная копия
настроек» → «Сохранить в файл», дальше открыть файл на телефоне,
скопировать целиком и вставить в поле импорта. Списки эмоутов оттуда
не берутся — модуль качает их с 7tv.io сам по id наборов, поэтому вы
с другом видите одинаковые картинки под одним словом.

При первом запуске, если наборов нет, подключается `bratishkinoff` —
как и в расширении. Одноразово: удалил из списка, сам не вернётся.

## Предложение подключить набор

Если в чат прилетает слово вида `имя_ник`, а такого эмоута у тебя нет —
модуль проверяет по API, есть ли такой стример и лежит ли эмоут с таким
именем в его наборе. Сошлось — слово подсвечивается, а в пикере сверху
появляется строка «МОЖНО ПОДКЛЮЧИТЬ» с превью и количеством эмоутов.
Тап — набор подключается, и слово тут же становится картинкой.

Где проходит граница «эмоут | стример», заранее не понять: в `ok_bratishkinoff`
подчёркивание одно, а в `SEXALARM_kanba_mx` ник сам с подчёркиванием —
стример тут `kanba_mx`. Поэтому разделители перебираются слева направо
(не больше трёх), и берётся первый вариант, который сходится по API.
Имя сверяется с учётом регистра: подключим набор — эмоут должен
отрендериться ровно тем словом, которое пришло.

Ответы кэшируются, в том числе «не нашлось», плюс стоит потолок в 40
запросов на сессию: чат с сотней незнакомых слов не должен превращаться
в сотню обращений к API. Выключается в настройках, «Предлагать наборы
стримеров».

В браузере рядом со словом рисуется чип с кнопкой. Здесь так нельзя:
чтобы слово в сообщении стало нажимаемым, пришлось бы подменить
`movementMethod` у чужого `TextView`, а через него ВК обрабатывает тапы
по ссылкам, упоминаниям и долгие нажатия. Ломать это ради кнопки — плохой
размен, поэтому слово только подсвечивается, а действие живёт в пикере.

## Как это выглядит

**В переписке.** Слово-код превращается в картинку прямо в строке, размер
привязан к размеру шрифта (1.8 высоты), так что при любом системном
масштабе текста эмоут остаётся в строке. Zero-width эмоуты накладываются
поверх предыдущего, пробел между ними съедается.

**Кнопка.** Круглая «7TV» в ряду иконок панели ввода, рядом со стикерами.
Если ряд опознать не удалось (ВК перекроил разметку) — модуль вешает
плавающую кнопку поверх экрана, её можно перетаскивать. Функциональность
важнее идеального места.

**Пикер.** Панель над строкой ввода, до 45% экрана, тёмная, той же
палитрой, что и поповер в браузере (`#1e1f24` / `#34363f` / `#4c8bf5`).
Именно над, а не поверх: иначе не видно, что вставилось в поле.

```
┌─────────────────────────────────┐
│ 7TV                           ✕ │
│ ┌─────────────────────────────┐ │
│ │ Поиск эмоута                │ │
│ └─────────────────────────────┘ │
│ ИЗБРАННОЕ                       │
│ [x][x][x][x][x][x] →            │
│ (Все)(Глобальные)(bratishkinoff)│
│ ┌─┬─┬─┬─┬─┬─┬─┐                 │
│ │ │ │ │ │ │ │ │                 │
│ ├─┼─┼─┼─┼─┼─┼─┤                 │
│ │ │ │ │ │ │ │ │   ↕ прокрутка   │
│ └─┴─┴─┴─┴─┴─┴─┘                 │
└─────────────────────────────────┘
```

Тап по эмоуту вставляет его **полное имя** (с постфиксом набора,
`ok_bratishkinoff`) в позицию курсора — как в веб-пикере, чтобы эмоут не
спутался с одноимённым из другого набора. **Долгий тап** — в избранное
и обратно.

Звёздочки в углу ячейки, как в вебе, здесь нет намеренно: на телефоне
в неё не попасть пальцем, а долгий тап — привычный жест.

Наборы сделаны чипами-фильтрами, а не заголовками секций: на телефоне
сетка узкая, и заголовки съедали бы половину высоты.

## Устройство

| Файл | Зачем |
|---|---|
| `Vk7tvModule.kt` | точка входа, хук `TextView.setText`, канарейка |
| `Replacer.kt` | разбор текста на слова и сборка Spannable |
| `Spans.kt` | `EmoteSpan`, стопка zero-width, мост анимации во View |
| `Service.kt` | защита служебных подписей (время, «(ред.)») |
| `Emotes.kt` | реестр имён, загрузка наборов с 7tv.io |
| `EmoteCache.kt` | картинки: скачивание, диск, LRU, декод |
| `SevenTv.kt` | резолв набора по ссылке, ID или нику стримера |
| `Suggest.kt` | поиск наборов по словам вида «имя_ник» из чата |
| `Net.kt` | HTTP из процесса ВК |
| `Inject.kt` | кнопка в панели ввода + плавающий запасной вариант |
| `PickerUi.kt` | панель пикера |
| `SettingsUi.kt` | настройки внутри ВК |
| `Config.kt` | конфиг в хранилище ВК |
| `SettingsActivity.kt` | экран-памятка, настроек в нём нет |

### Почему хук именно за `TextView.setText`

Классы ВК обфусцированы R8 и переименовываются от версии к версии — модуль,
завязанный на них, ломался бы каждое обновление. Платформенный `TextView`
стабилен, поэтому цепляемся за приватный
`setText(CharSequence, BufferType, boolean, int)`: через него `TextView`
прогоняет вообще все варианты `setText`, включая `setText(int)`.

Панель ввода ищется так же «снаружи»: находим `EditText`, поднимаемся на
пару уровней и берём ряд, где рядом с полем уже висят `ImageView`.

### Что сломает обновление ВК

Не факт обновления сам по себе, а переезд чата на Jetpack Compose: там
`TextView` не используется вообще, и хук перестанет что-либо находить —
молча, без крашей. На этот случай в модуле есть канарейка: через 30 секунд
после старта она пишет в журнал, сколько текстов прошло через хук
и сколько подмен сделано. Ноль подмен при живых наборах — повод смотреть,
что изменилось.

Если ВК начал падать — поставить обратно оригинальный APK из Play Store.
Все хуки обёрнуты в `try/catch` (`L.safe`), потому что неперехваченное
исключение в чужом процессе роняет не нас, а ВК.

## Сборка

```bash
export JAVA_HOME=/opt/homebrew/opt/openjdk@17
export ANDROID_HOME=/opt/homebrew/share/android-commandlinetools
cd android && gradle assembleDebug
```

APK окажется в `app/build/outputs/apk/debug/`.

Зависимость `de.robv.android.xposed:api` подключена как `compileOnly` —
в APK её классы попадать не должны, реализацию подставляет LSPatch.

## Чего пока нет

- автозаполнения при наборе текста, как в браузере
- «своих» эмоутов вручную (приезжают только импортом из расширения)
